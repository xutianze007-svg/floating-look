# A. — Floating Look

本地交互首页。人物、商品和前后丝带分别播放，点击后聚焦对应元素并显示商品信息。

## 运行

需要 Node.js 20 或更新版本，无需安装依赖。在此文件夹运行：

```sh
npm run dev
```

打开 http://127.0.0.1:4173 。也可双击 `启动预览.command`。

## 已实现

- 11 件独立配饰；人物使用视频 28 待机，点击人物使用视频 29。
- 所有素材有独立位移与小幅旋转；前后丝带分层。
- 点击移动、放大、聚焦；返回和 Escape；暂停/继续动态。
- 配饰慢动作展示、分类筛选、商品搜索、集合浏览。
- 本地购物袋：加入、移除、数量与小计，刷新后保留。
- 窄屏布局、键盘操作、减少动态效果偏好、后台暂停。
- 视频已转成网页播放副本，原视频未修改。

## 合成方式与限制

用 Canvas 对视频逐帧移除近似纯色背景。人物从图像边缘连通的浅色区域提取背景，避免直接挖空白T恤；配饰和丝带使用较柔和的颜色阈值。固定深度顺序为背景→后丝带→人物→配饰→前丝带→UI。没有把整张截图当作页面。

这是实时背景处理，不是经过人工逐帧修边的 alpha 视频。发丝、薄丝带、白色鞋边和透明玻璃仍可能有边缘损失；正式投放建议用专业视频分割、精修透明度后导出网页兼容格式，降低实时计算成本。为了减少首尾跳变，在末尾叠加初始帧做轻量淡化；原素材不是严格无缝循环，不能保证身体动作的物理闭环。

11个配饰全部可点；人物、两条丝带、耳机、包与挂件默认播放，其余商品在悬停或聚焦时播放。价格、描述均为示例。购物袋是浏览器本地演示，不连接支付、库存或订单。其他人物没有全身视频，因此没有伪造可切换的角色。

## 文件

`index.html` 页面；`style.css` 样式；`app.js` 交互与背景处理；`server.mjs` 本机静态服务器（支持视频范围请求）；`assets/` 透明静态图和背景；`media/` 网页视频副本。
