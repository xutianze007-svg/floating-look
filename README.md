# Floating Look

公开演示：https://xutianze007-svg.github.io/floating-look/

分享上面的网页地址即可，无需 GitHub 账号。此仓库为已确认的 v2，包含 City Designer 和 Weekend Dad 的动态素材及交互。

## 本地预览

需要 Node.js 20 或更新版本。执行 `npm run dev`，打开终端显示的本机地址。本机地址不能分享给其他设备。

## 发布

主分支更新后，GitHub Actions 将页面、CSS、JavaScript、字体、图片和视频发布到 GitHub Pages。采用相对资源路径，支持 `/floating-look/` 子目录。部署不包含本地服务器。

购物袋和价格为交互演示，不接支付或订单。
